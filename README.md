# Машинное обучение в задачах обработки текстов на естественных языках

## Описание

Данный проект посвящён применению методов машинного обучения для анализа текстов и выявления кибербуллинга в постах социальной сети Twitter.  
Основная цель — построить модель, которая сможет автоматически классифицировать сообщения по типу кибербуллинга (религия, пол, возраст, этничность и т. д.) и отличать их от нейтральных постов.

Проект реализован в рамках курсовой работы по дисциплине *«Машинное обучение»* Финансового университета при Правительстве РФ.

---

## Цель исследования

Применить методы машинного обучения для классификации текстов с целью выявления признаков кибербуллинга и определения его типа.

---

## Задачи проекта

1. Сбор и анализ данных.  
2. Предобработка текста (очистка, лемматизация, удаление стоп-слов, emoji, ссылок).  
3. Преобразование текстов в числовой формат с помощью TF-IDF векторизации.  
4. Обучение и сравнение нескольких моделей машинного обучения.  
5. Подбор гиперпараметров и выбор наилучшей модели.  
6. Проверка модели на тестовой выборке и оценка метрик качества.

---

## Используемые данные

- **Источник:** [Kaggle – Cyberbullying Classification Dataset](https://www.kaggle.com/datasets/andrewmvd/cyberbullying-classification)
- **Объём данных:** 47 692 твита  
- **Столбцы:**
  - `tweet_text` — текст поста  
  - `cyberbullying_type` — тип кибербуллинга  

**Типы кибербуллинга в датасете:**
- `religion`
- `age`
- `gender`
- `ethnicity`
- `not_cyberbullying`
- `other_cyberbullying`

## Результаты

| Модель | Accuracy | F1-score |
|---------|-----------|----------|
| Linear SVM | **0.837** | 0.836 |
| Gradient Boosting | **0.838** | 0.838 |
| Logistic Regression | 0.824 | 0.821 |
| Naive Bayes | 0.752 | 0.760 |

**Вывод:**  
Обе лучшие модели (SVM и Gradient Boosting) показали сравнимые результаты, однако **Linear SVM** предпочтительнее благодаря простоте и интерпретируемости.  
Метрика **PR-AUC = 0.91**, что указывает на высокое качество классификации.
